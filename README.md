# FC Sidekick for Windows

Download the [latest ZIP package](https://github.com/realtrx9/fcsidekick-releases/releases/latest), extract the whole package, then run `Start FC Sidekick.cmd` from the extracted folder. Keep the `runtime`, `scripts`, and `web` folders beside the launcher.

حمّل حزمة ZIP من صفحة الإصدارات، وفك ضغطها كاملة، ثم شغّل `Start FC Sidekick.cmd` من داخل المجلد. ملف التشغيل وحده يحتاج بقية ملفات البرنامج الموجودة في الحزمة.

`latest.json` is the public update manifest used by the in-app **تحديث البرنامج** button.
