# FC Sidekick for Windows

Current version: **0.2.15**. Download the [latest ZIP package](https://github.com/realtrx9/fcsidekick-releases/releases/latest), extract the whole package, then run `Start FC Sidekick.cmd` from the extracted folder. Keep the `runtime`, `scripts`, and `web` folders beside the launcher.

للمستخدم الجديد: حمّل [الإصدار 0.2.15](https://github.com/realtrx9/fcsidekick-releases/releases/tag/v0.2.15)، وفك ضغط حزمة ZIP كاملة، ثم شغّل `Start FC Sidekick.cmd` من داخل المجلد. ملف التشغيل وحده يحتاج بقية ملفات البرنامج الموجودة في الحزمة.

لمن لديه البرنامج مسبقًا: افتح البرنامج واضغط **تحديث البرنامج** للحصول على الإصدار الجديد مع الاحتفاظ ببيانات ناديك المحلية.

`latest.json` is the public update manifest used by the in-app **تحديث البرنامج** button.
